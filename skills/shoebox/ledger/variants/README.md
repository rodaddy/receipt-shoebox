# variants

Four starter category lists. At install the business-type question
(`installer.md` Section 4.5) maps the user's answer to one of these and copies
it into `../categories.md`, replacing what is there.

- `trades-and-field-service.md` - the default when unsure and they buy materials.
- `professional-services.md` - consulting, agency, bookkeeping, law, anyone
  billing time.
- `retail-and-food.md`
- `generic-smb.md`

They are starting points, not fixed lists; the user edits `categories.md` after
install.
