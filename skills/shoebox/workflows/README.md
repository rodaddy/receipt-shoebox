# workflows

The four things the user can ask for, one file each. Each reads
`../USER-CONFIG.md` first to resolve the books folder and the job-tracking
setting.

- `process-receipts.md` - read the pile, ask the job question once, append to
  `ledger/expenses.md`.
- `month-end-export.md` - turn the month's table into the accountant CSV and the
  job-costs CSV, with the full CSV escaping rule.
- `flag-review.md` - duplicates, capital question, outliers, unreadable,
  uncategorized; ask, do not assume.
- `month-in-review.md` - three sentences comparing this month to prior months,
  plus the add-a-bucket offer.
